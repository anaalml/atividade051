# tutorial051 - Agendamento de Evento

Aplicação desenvolvida em Flutter para gestão e agendamento de eventos, permitindo a seleção de serviços, configurações de notificação e personalização de tags.

// Resumo do Desenvolvimento

Neste projeto foi implementado um formulário interativo de agendamento que utiliza diversos componentes do Flutter para captura de dados do utilizador:
- Gestão de estado local com `StatefulWidget`.
- Seleção de opções com botões do tipo `OutlinedButton`, `ElevatedButton`, seletores do tipo `RadioGroup`, `FilterChip` para as tags do evento e dropdowns interativos.
- Correcção e tratamento de erros de inicialização de variáveis dinâmicas (`late`).
